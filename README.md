# ContribFlow

![ContribFlow Logo](docs/images/logo.png)

## Smart Contribution Management Platform

ContribFlow is a Django-based platform designed to help groups, communities, and organizations manage members, contributions, payments, and financial reports.

## Features

- Member Management
- Contribution Tracking
- Payment Management
- Reports & Analytics
- Role-Based Access Control

## Technology Stack

- Python
- Django
- MySQL
- Bootstrap 5
